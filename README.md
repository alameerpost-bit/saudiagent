# Saudi Agent

بوت لتحليل ومتابعة أسهم السوق السعودي (تداول) وإرسال توصيات ومراجعات دورية. هذا المستودع هو المشروع النشط الوحيد.

## الحالة الحالية
- محرك التوصيات الحالي: `bot.py`
- مصدر بيانات السوق الأساسي: Sahm Capital، وفق التحقق من صحة الاستجابة وتوقيت السوق.
- توصيات الإغلاق: `.github/workflows/daily.yml` عند 16:15 بتوقيت الرياض، الأحد–الخميس.
- مراجعة التوصيات: `.github/workflows/morning-review.yml` عند 10:15 بتوقيت الرياض، الأحد–الخميس.
- مراقب الجدولة: `.github/workflows/schedule-watchdog.yml`.
- الاختبارات: `python -m unittest discover -s tests -v`.

## مبادئ التشغيل
- لا تُعرض البيانات المتأخرة على أنها لحظية.
- لا تصدر إشارة دخول إذا تعذر التحقق من البيانات المطلوبة أو توقيتها أو تغطية المسح.
- لا يوجد تنفيذ تداول آلي أو مجدول.
- منسق المهارات الأحد عشر يعمل حالياً بوضع تحقق ظلّي: يربط الفحص الفني الحالي وإدارة رأس المال والمخاطر ومراجعة الأسعار، دون تغيير الاستراتيجية أو التوصيات.
- التحليل المالي والأخبار والإفصاحات والمحفظة والوسيط ما زالت غير مفعلة حتى تتوفر موصلات سعودية موثوقة ومصرح بها.
- لا تُغيّر حدود رأس المال أو الاستراتيجية دون اختبار ومراجعة.
- لا تضع مفاتيح API أو بيانات الحساب في المستودع.

## تطوير واختبار
```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

التطويرات التشغيلية المعتمدة لهذا المشروع تُنفذ على `main` بطلب صريح، مع اختبارات GitHub Actions قبل اعتماد أي تشغيل فعلي. التعديلات التي قد تغير الاستراتيجية أو تتيح أوامر التداول تتطلب موافقة منفصلة.
